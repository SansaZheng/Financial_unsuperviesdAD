# 金融无监督异常检测统一实验协议 v1

在本轮真实金融测试成绩产生前固定。用户确认沿用全部 9 组数据。共 10 个任务配置（SD-FMM stock/crypto 分开）、10 个独立方法、3 个种子 42/43/44，计划 300 次运行。数据及原划分来自 KronosAD 固定提交 `2c0e70eb9461081c49a4ef4cfd62f4560f345477`，本仓库模型运行不依赖 Kronos 权重或模型代码。

## 训练与预处理

- 所有方法每个种子均从训练分区**均匀无放回抽样最多 8192 条**，不按标签筛正常、不按类别采样；相同种子、相同数据的十种方法使用相同训练索引。此上限依据本机近邻计算资源设定，不依据模型效果。不是全量训练，不能直接与上一轮 5 万训练上限的 Kronos 结果混排比较。
- 仅该训练抽样拟合中位数、IQR/1.349 缩放；IQR 退化时用训练标准差，再退化用 1。删除训练全缺失列，对训练出现过缺失的列追加缺失指示变量。
- 全部方法的训练、校准、测试**统一将数值特征限制在标准化后的 [-8,8]**；评分也基于同一变换后的观测。没有方法单独使用未截断目标获得额外极端值信息。截断和指示变量的局限均是本轮共同输入设定。
- 传统方法超参数见方法表，全部预先固定，无基于标签调参。神经方法 Adam，lr=0.001、batch 最多 256、固定 400 步、有放回训练抽样；不按验证标签早停。Deep SVDD 按其定义另有 200 步无标签 AE 预训练，中心固定，weight_decay=5e-7；其他两种神经方法 weight_decay=0。
- VAE 训练：Gaussian NLL（各维相加、单位方差）＋解析 KL。log variance 限制 [-12,8] 保证数值稳定。评分用固定种子 1729 产生的 4 对 antithetic 标准高斯，共 8 个样本，MC 估计负 ELBO；不使用确定性后验均值重构冒充完整 ELBO，不按预测批次重抽分布。

## 阈值与评价

- 独立校准段均匀无放回抽样最多 100,000 条，种子为训练种子+100。训练和校准过程不打开对应目标文件，不接收目标参数。记录阈值后，才在全量留出测试上评分并打开测试标签。
- 主阈值为固定 POT：初始分位数 q=0.85、risk=0.01、至少 20 个非退化超额。上尾 GPD 的位置固定 0。原分数可以为负；只要求超额为正。这是固定阈值，不是在线 SPOT，名义 risk 不是实际 FPR 保证。
- **预先另报告校准 99% 分位阈值作为统一敏感性对照**。对所有方法都计算两套操作点，不用测试标签选择其中较好者。POT 对离散／退化分数拟合失败时，主指标明确 N/A 和原因，分位阈值仍另列，绝不暗中替换成“POT”。
- `score>=threshold` 判异常；不使用 point adjustment、事件扩展或测试最优 F1 阈值。未知标签 -1 只在评价时屏蔽，绝不当正常；未知标签可以参加无标签训练和校准。
- 逐种子报告 Precision、Recall、F1、FPR、TP/FP/FN/TN、AP、梯形 PR-AUC、ROC-AUC、测试正例率；报告均值与总体标准差 ddof=0，不把三种子标准差称作置信区间。无真值或单类测试集相应曲线指标为 N/A。

## 数据／标签粒度

沿用原来的特征与分区，源文件未修改。Sapienza 只使用 15S，5S/25S 是同批事件的不同粒度，不重复计为独立数据集。

| 配置 | 留出规则 | 评价单位与限制 |
| --- | --- | --- |
| Sapienza 15S | 按币种分组，51/17/17 币种 | 原始 12 维工程特征；作者标注起点块，不等于完整操纵持续时间 |
| TSTR | 去重后的原序列分组 | 全段 20 维收益统计，序列标签；回顾性，不生成点标签；训练/校准约半数为正，违背稀有异常假设；历史分组有标签分层，模型训练本身不使用标签 |
| SD-FMM stock/crypto | 按原序列分组 | 原值、差分和过去/当前滚动统计，共 11 维；点标签；出版者完整序列归一化可能含未来信息；重用公开 test 数组研究划分，不是原论文零样本复现 |
| ULB | Time≤86400 / ≤129600 / 之后 | 29 维数值交易特征，交易标签；不把 Time/Class 当输入 |
| Elliptic | 时间步≤29 / ≤34 / 35..49 | 165 维节点特征，不使用图边；未知节点参加无标签拟合但不参加最终已知标签评价；聚合特征可能含后续邻居信息 |
| PaySim | 仅时间计数得到约 60/20/20，step 边界 281/355 | 旧余额、金额、交易类型；排除账户、事后余额、isFlaggedFraud；合成交易 |
| TabFormer | Year≤2016 / 2017 / ≥2018 | 48 维固定交易特征；排除 User/Card/商户标识；合成；不是未见用户测试 |
| AML HI-Small | 仅时间计数约 60/20/20，2022-09-06 13:36 / 09-08 16:12 边界 | 52 维金额／币种／方式特征；排除账户和洗钱模式标注；合成；没有跨账户图模型 |
| IEEE-CIS | 仅官方训练表，DT≤9504000 / ≤12614400 / 之后 | 数值交易字段，不接身份表；官方 test 无真值，不计算其 F1；原始数据受限，仅本地使用 |

时间留出允许同一账户跨期，不能声称未见账户泛化。金额收付、错误标记等部分特征适用于离线交易记录分析，不构成支付授权前拦截验证。部分数据集可能存在未能审计的跨窗口重叠、上游变换或跨来源事件重叠。不同粒度、真伪及正例率不一致，不做跨数据集混合平均排行榜。
