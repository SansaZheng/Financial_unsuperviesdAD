# 固定协议：HALO教师几何、字段重构增益与独立模拟世界验证

生成新验证数据及任何新金融成绩前固定；旧测试用于设计，本轮旧任务仍属回顾性开发。两个固定主方案：HUGE `fusion`，HIMVH `cm_skill_tail`；全部其他配置仅作消融，不按数据集换主方法。

## 1. HUGE

保留原模型、128隐藏维、300更新、学习率0.0005、原排序／正则／蒸馏损失及边。四个新拟合骨干：legacy（40维输入、原HALO教师）、dual（48维双通道、双通道HALO）、decoupled（48维双通道、40维原教师）、role_decoupled（16维分角色输入、40维原教师）。40维教师仅按原训练图公共统计变换，保持原几何；其统计不依赖测试数据或标签。教师与学生分离用于避免上轮对齐压缩直接改变教师信号。

八种评分：legacy_embed、dual_embed、decoupled_embed、role_decoupled_embed、teacher_only、fusion（主）、native_fusion、legacy_fusion。embed沿用负邻居余弦；teacher_only直接使用原40维输入HALO，训练免费，明确不是训练后HUGE原评分。融合是对应embedding与原始HALO各自经无标签校准经验上尾-log(p)映射后等权平均；同一固定映射用于测试，p=(1+校准误差/分数>=当前值条数)/(n+1)。fusion使用decoupled骨干，native_fusion使用dual，legacy_fusion使用legacy。三种融合均保留原教师，隔离训练教师改变的作用。含教师的评分为新适配，不宣称作者原版。

## 2. HIMVH

保持上一轮一致遮蔽任务和原m/cm骨干。对字段g，用原8192训练目标的预处理后逐坐标中位数作为常量预测器。在原无标签校准样本上比较该常量的字段MSE b_g与冻结模型字段MSE e_g：skill_g=clip(1-mean(e_g)/max(mean(b_g),1e-8),0,1)。主权重 w_g正比d_g*(0.25+0.75*skill_g)，归一化后聚合字段尾证据；d_g为字段宽度。常量预测器仅用训练数据，误差及权重只用校准数据。0.25下限预先固定，避免未展示重构增益的字段被全部删除；该增益衡量自监督可预测性而非欺诈相关性。

每个m/cm共八评分：field、flat、tail、tail_flat（已知对照），skill_tail（主），skill_raw（同权重聚合原始误差），skill_equal_tail（去维数先验），skill_hard_tail（去0.25下限，所有权重为0退回维数先验）。BankSim/S-FFSD复用12个已核验模型及逐字段误差；独立验证新拟合6个m/cm模型，仍800×128且目标样本8192。所有无标签源样本参与，不按真实正常标签清洗。

## 3. 独立验证数据

仓库CardSim官方ZIP此前只有代码和公共调查输入，没有生成过实验数据。固定官方代码ZIP SHA并原样调用；seed=2026111707，n_payers=1024，n_days=90，payer_payee_factor=1，其余生成参数全部默认。选择固定规模控制图谱资源，不依据标签或成绩调参。完整生成交易保留，按完整时间戳累计计数60/20/20划分，不另抽异常。付款账户与收款账户使用原生ID，不发明边。图仍4时间快照、最多4096个固定SHA付款账户和全部对手方，付款账户评价；本模拟世界最多1024付款者。

交易字段：log_amount(1)、log_distance(1)、credit_card onehot(2)、remote onehot(2)、payee哈希(16)、日内时钟sin/cos(2)，共24维／6字段；日期和payer ID不入特征。超图四视图为payer、payee、credit_card、remote，按时间稳定排序的原4窗口构建。欺诈标记、生成器后验概率及内部似然比不入任何学习输入。原生构图键可能携带遮蔽字段的结构信息，与旧方法相同，披露而不称彻底隐藏类别。

这是独立生成、先固定方法再解封成绩的新来源验证，不是真实世界银行外部验证。标签为模拟器规则；一个模拟世界也不能代表多个独立真实数据集。所有主方案／对照在新数据集各自训练与校准分区拟合，测试不拟合参数；称跨来源协议验证，而不是把旧银行模型零样本直接迁移。

## 4. 对照和不变条件

原101输入文件、2旧适用任务的划分和完整测试一字节不变；旧9交易任务、2账户任务的最佳方法表保留。原任务其余模型复用已核验成绩。新CardSim重新运行此前2旧任务AP及两种F1获胜方法的并集：交易HBOS、LOF、VAE；图EB-GAD发布版、Audit-HCL零标签适配。设置用原实现：VAE400更新、Audit200更新，原8192训练目标和100000校准上限。EB训练免费、阶段内转导，三种子相同也如实报告；无需假造随机差异。CardSim所有候选使用相同新划分／测试样本，不拿旧成绩与新数据比较。

种子42/43/44；训练预处理沿用median/IQR/1.349、std退回、clip±8。POT初始q.85、risk.01、min20，失败N/A不替换；独立q99。AP、梯形PR-AUC、ROC、Precision/Recall/F1/FPR和混淆计数；3种子均值±样本SD，无点调整、标签阈值、早停或翻分数。

预计231配置／462条操作点：72 HUGE评分（36拟合）、144 HIM评分（6新拟合、12旧父模型）、15新数据基线（12拟合、3训练免费）。总54次新拟合。所有主方案与消融固定于新数据生成前；所有成绩保存后统一查看，不按新验证成绩继续调整。检查点／分数／阈值先保存并形成gate再打开测试标签；生成器产生标签是数据制作，不是模型获取训练标签。
