# HUGE、HIMVH-Zero、SD-FMM-Zero 固定实验协议

日期：2026-11-17。研究任务为金融零标签适配，**不是三篇论文的原始成绩复刻**。配置在本轮金融结果查看前固定；旧测试集此前已经用于多轮方法诊断，因此这不是全新盲测，也不声称确认了统计显著性。旧代码、原始数据、既有实验保持不变。

HUGE仅使用已保存的真实账户关系，4快照40维特征及去重无向边并集（训练GCN补自环）。共用快照级训练鲁棒缩放，不采用原作者适于非负属性的行和归一化。监督信息为0；图内HALO／损失也覆盖收款方，与Audit-HCL的完整图信息范围一致。最终只评估既有付款账户，不把角色节点解释成真实统一身份。排序损失每步均匀抽512节点、邻居／非邻居和对齐统计用完整图；固定300更新、hidden128、Adam lr=.0005、kd=.5。稳定softplus重写原排序公式；非邻居余弦总和用代数恒等式消除完整N×N矩阵。HALO及GCN／梯度／损失有数值参考测试。

HIMVH视图：S-FFSD的Source、Target、Location、Type；BankSim的customer、merchant、category、gender（原生身份或类别键，gender是属性视图，不是伪造账户边）。每视图按时间及原行号稳定排序，window=4，组短于4不补造超边；超边重叠时节点消息取均值，这是论文未明确的实现补全。新颖度beta=1，hidden256，3层，4视图；固定200更新、每步损失抽512训练节点、Adam lr=.001、输入20%遮蔽；其他训练节点用作无标签消息上下文。Eq.6按其所列 `KL(M||P)` 实现，区别于常规正向Jensen–Shannon。标签差异通道常数0，不用聚类或真实标签伪装该通道。标签嵌入为零。重构头为256→256→特征维、BN/ReLU/dropout.1，MSE训练；不是原分类头。每阶段单独构图，训练仅既有8192抽样行，校准／测试使用其各自完整阶段上下文，最终评价原校准索引及全量测试行。**这是离线交易检测，图关系是相对逐行基线的额外信息；不声称相同信息预算或在线因果性。**

SD-FMM-Zero只在6组有真实序列边界的任务运行，不把ULB、BankSim、S-FFSD的全局行序列当作同一资产。每个既有目标行取本序列／分区内过去和当前共160行，冷启动重复首行，绝不跨序列或使用目标后数据。Transformer可在窗口内双向，但仅输出末行风险，故目标时刻无未来信息。它比Kronos的32行历史、逐行基线有更多历史信息，报告明确此差异。

每步从既有训练目标索引均匀取16行窗口；源窗口可能已有异常，不能称为已确认正常。在其中随机13行片段对所有通道做db2小波分解（2层、symmetric），对细节系数加入随机符号、幅度为局部std下限.1的1至3倍的扰动，重构截到13行并clip[-8,8]，仅此区间为自产1目标，其余为0；未扰动窗口的自产目标全0。这替代原作者需异常示例的领域生成器，并不使用任何真实异常标签。保留原对比损失 `-log(1-sigmoid(cos/.5)+1e-8)`，总损失为BCE+.5对比。固定400更新、Adam lr=.001，末步模型用于评价；不挑最佳epoch、不使用任何验证标签。可能的源异常污染及合成／真实异常不匹配将据实分析。

## 沿用的共同协议

- 复用[原协议](zero_label_protocol_CN.md)全部9组输入文件并逐一验证81个基准SHA256；账户图另验证 `recent_zero_graph_inputs.json` 中的既有图、ID、标签、清单字节。不会重新按标签筛选样本。准备缓存时可写入标签文件、用于整体完整性校验可计算文件摘要；模型训练／阈值绝不解析训练／校准标签，清单内标签数量不参与算法。
- 交易／行情训练抽样最多8192行，校准最多100000行，随机索引规则及seed42/43/44不变；测试全量。快照图付款账户、训练共同缩放器、校准／测试对象不变。SD-FMM使用额外历史、HIMVH使用额外原生关系、HUGE使用账户边，不能把这些上下文差异隐藏为完全相等的信息预算。
- 仅训练特征拟合median/IQR缩放（std回退、clip[-8,8]），与原基线相同。先完成模型重载一致性核验、保存分数及阈值，再解析测试标签。
- 共同阈值保持原POT（初始q=.85、risk=.01、min_peaks20）及独立校准q99；失败记N/A，不用护栏或分位数冒充原POT。`score>=threshold`报警。分数方向预先固定，不按测试AUC翻转。
- AP、梯形PR-AUC、ROC-AUC，以及两操作点的异常类Precision/Recall/F1/FPR和混淆计数；不做点调整。未知标签只在最终指标排除。均值±样本标准差，3种子，逐任务排名，两个轨道分开。
- 正式30次：HUGE 2×3，HIMVH-Zero 2×3，SD-FMM-Zero 6×3；形成60条操作点记录。所有预定结果都报告，不选择有利种子。未支持任务为N/A，不填充其他方法成绩。
- 固定训练预算不等于相同FLOPs或相同原论文epoch。比较检测指标，不据此声称速度最优。
