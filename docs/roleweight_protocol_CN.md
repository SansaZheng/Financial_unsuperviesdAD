# HUGE 角色适配与 HIMVH 字段评分：预先固定的实验协议

本协议在新一轮成绩产生前固定。依据上一轮测试集消融提出方案，因此属于回顾性开发评估，不能称为独立盲测。模型训练、字段权重、阈值拟合均不使用真实标签；不按测试成绩选不同数据集的主变体。

## 固定主方案和消融

HUGE 主方案为 `dual`：保留去角色标识后的32维原数值通道，同时加入16维角色语义对齐通道，两块分别除以维数平方根。原数值通道保留付款／收款方向及绝对行为信息；对齐通道用全训练图共享中心和尺度，使两种角色的计数、均值、标准差、最大值位置可比。不是把账户身份当作异常。全部8变体：legacy(原40维)、role(上一轮分角色中心和尺度16维)、numeric(原32维)、aligned(共享尺度16维)、centered(分角色中心但共享尺度16维)、dual(主方案48维)、dual_center、dual_role。每个变体固定原网络／损失、300更新。维数改变也改变参数量及初始化轨迹；双通道对比不能单独归因于角色对齐。

HIMVH 主方案为 `cm_tail`，沿用上一轮完整原生上下文、修正遮蔽的冻结模型。对每个字段误差 e，令 p=(1+校准集中误差>=e的数量)/(n+1)，用 -log(p)作为统一尾部证据，再等权平均。相同映射用于校准及测试；并列采用保守上尾，最大证据有界，常量字段校准证据为0。另保留抽样上下文m作为消融。每个骨干8种评分：field(原字段均值)、flat(按字段维数)、mean_scale(除校准均值)、median_scale(除中位数，小于等于1e-8退回均值，再退回1)、tail、tail_flat、tail_max、tail_corr(根据校准尾证据的正相关冗余逆权重)。相关权重为 1/(1+正相关系数之和)，再归一化。不能将高重构误差直接解释成高欺诈信息。

字段校准只使用原有无标签 calibration 误差，不拟合测试分布。校准变换与POT共用校准样本，不提供严格的有限样本误报保证。HIMVH不重新训练：复用12个已核验冻结检查点和逐字段分数，固定网络以隔离评分因素；基线field/flat必须逐项重现上一轮原始分数。HUGE重新训练48个模型。总计144配置、288阈值操作记录、48次新拟合、96组新HIMVH评分。未改变的旧经典方法与SD-FMM结果复用并注明。

## 不变的公平条件

种子42/43/44，101个输入文件逐字节SHA256核验，沿用原训练／校准／完整测试划分及8192训练目标、最多100000校准样本；HUGE仍使用完整训练图，不将保存的8192参考索引误作损失节点上限。HIMVH使用原模型的相同索引和预处理。图仅评价付款账户，9个交易数据集与2个账户图任务分开。新增方法仅适用BankSim/S-FFSD各自对应任务，不伪造其他任务成绩。

原POT初始分位数0.85、风险0.01、最少20峰；失败记N/A，另独立报告q99。AP、梯形PR-AUC、ROC-AUC、Precision、Recall、F1、FPR与混淆计数；报告3种子均值±样本标准差。原始异常方向，不翻转，不point-adjust，不用标签定阈值或早停。分数／阈值先持久化并形成label-access gate，再读取测试标签评价。主对比池仅增加dual和cm_tail，其他变体仅作消融。旧HUGE legacy/role用本轮重训锚点替换，避免同名重复。
